# KNN Student Result Prediction

A simple Machine Learning project using the **K-Nearest Neighbors (KNN)** algorithm to predict whether a student will **Pass or Fail** based on study hours, attendance, and previous score.

## Features

- KNN Classification
- Train-Test Split
- Feature Scaling using StandardScaler
- Accuracy Evaluation
- Confusion Matrix
- Prediction for a new student

## Dataset

The `student.csv` dataset contains:

- Study Hours
- Attendance
- Previous Score
- Result (Pass/Fail)

## Technologies Used

- Python
- Pandas
- Scikit-learn
- Jupyter Notebook
